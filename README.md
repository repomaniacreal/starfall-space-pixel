# STARFALL: VOID RUNNER

STARFALL: VOID RUNNER is a browser-based pixel-art space adventure game. Pilot a starfighter through deep space, dodge cosmic hazards, use special abilities, collect items, and reach the Stargate.

## Features

- Retro pixel-art graphics and arcade-style interface.
- Space backgrounds featuring stars, nebulae, planets, moons, and asteroids.
- Cosmic obstacles, including planets, black holes, meteors, and alien threats.
- Four space sectors to explore.
- Starfighter movement, dash, and sonar abilities.
- Collectibles, runes, combo scoring, and progression.
- Title, pause, victory, and defeat screens.
- Keyboard and supported touch controls.
- Local high-score and preference storage.
- Standalone HTML file with no external assets or libraries required.

## How to Run

1. Download the project file named index.html.
2. Open index.html in a modern web browser.
3. Select BEGIN LAUNCH on the title screen.
4. Navigate through the space sectors and avoid obstacles.
5. Use your abilities strategically to survive.
6. Reach the Stargate to complete your mission.

No installation, build process, or package manager is required.

## Controls

- Movement: W, A, S, D or Arrow Keys
- Dash: Space
- Sonar Pulse: E
- Pause or Resume: Esc or P
- Confirm or Restart when available: Enter

On supported mobile devices, use the on-screen touch controls.

## Scoring and Progression

- Collect items to increase your score.
- Chain successful actions to build combos.
- Use dash to avoid dangerous obstacles.
- Activate sonar to interact with nearby targets.
- Survive and progress through all four sectors.
- Your best score is saved locally when browser storage is available.

## Technologies

STARFALL: VOID RUNNER is packaged as a standalone HTML file.

index.html

## Compatibility

Use an up-to-date browser for the best experience.

Audio playback may require an initial user interaction because of browser autoplay policies. If browser storage is unavailable, saved preferences and high scores may not persist after closing the page.
